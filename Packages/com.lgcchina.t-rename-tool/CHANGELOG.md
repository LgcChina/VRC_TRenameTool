# 修改日志

## 2.1.1 - 2026-11-26

### 更新内容

- 修复“清空译文”按钮在译文框仍处于编辑焦点时清空失败的问题。
- 清空操作现在会释放键盘焦点、重置文本框滚动位置、清空解析结果与条目译文，并在 GUI 事件结束后再次确认清空状态。

### 安装与升级

- 包名保持 `com.lgcchina.t-rename-tool`，可直接覆盖同名包。
- 要求 Unity `2022.3` 与 VRChat Avatars SDK `3.x`。

### 容易踩的坑

- 清空后需要重新粘贴译文并点击解析，应用按钮不会继续使用之前的解析缓存。

## 2.1.0 - 2026-11-26

### 更新内容

- 将界面中的“Avatar 根物体”改为“待翻译物体”，相关按钮同步改为“使用当前选中物体”和“扫描待翻译按钮”。
- 新增“找到的菜单来源”分组：MA/VRCFury 按场景物体分组，原生 VRC 菜单按资源分组。
- 每个来源显示类型、条目数量、Hierarchy/资源路径，并提供“定位”按钮；展开后可查看该来源包含的原文。
- 来源复选框现在同时控制导出、译文校验、修改预览与最终应用；切换来源会安全清空旧译文并重建 ID。
- 导出编号从实验阶段的 `LGC0001` 改为更简洁的 `ID0001`，修改预览不再显示技术 ID。
- 预览改为单行顺序：复选框、`MA`/`VRCFury`/`VRC` 类型、原名、译名、路径和定位按钮。
- 搜索范围增加来源类型、来源物体名称和完整路径。
- 应用按钮移到窗口固定底栏，不再随内容滚动；底栏同时显示校验状态、所选修改数、错误数和警告数。
- 译文在校验后再次被手动编辑时会立即使旧校验失效，必须重新解析，避免应用上一次解析缓存。
- 点击“从剪贴板粘贴译文”会先把完整内容写入右侧译文框并刷新显示，再执行解析；解析失败时粘贴文本仍保留供用户修正。
- 完全移除“允许修改 Packages 内的菜单资源”选项。Package 原生菜单在扫描时跳过，写回核心也始终拒绝修改 Package 资源。
- 保持场景中 Package Prefab 实例的属性覆盖能力，因为该操作不会修改包源文件。

### 安装与升级

- 包名保持 `com.lgcchina.t-rename-tool`，可直接覆盖同名包。
- 要求 Unity `2022.3` 与 VRChat Avatars SDK `3.x`。
- Modular Avatar 和 VRCFury 为可选支持，不作为强制包依赖。
- 工具尚未正式发布给用户，因此 `2.1.0` 不保留实验版 `LGC0001` 导入兼容；更新后请重新扫描并复制 `ID0001` 格式的新文本。

### 容易踩的坑

- 在翻译网页中保留 `ID0001` 一类 ID；预览中不显示 ID 属于正常设计。
- 已粘贴译文后切换来源会清空译文，这是为了避免新旧 ID 对应错位。
- 取消勾选某个来源后，该来源不会导出、校验、预览或应用。
- `Packages/` 内的原生菜单资源不会被修改；需要翻译的原生菜单应位于项目 `Assets/` 中。
- `Assets/` 下共享的原生菜单资源一旦修改，会影响所有引用它的 Avatar。
- VRCFury 路径按层级拆分，单个译文中不能包含 `/` 或 `\`。
- MA 空 `label` 会写入译文，但 GameObject 名称保持不变。
- 应用后需要用户自行保存场景或资源；工具只负责修改与 Undo 记录。

## 2.0.0 - 2026-11-26

### 更新内容

- 完整重构旧版批量 GameObject 重命名工具，改为专门处理 VRChat 菜单显示文字。
- 新增原生 `VRCExpressionsMenu` Control、Puppet Label 和递归子菜单扫描。
- 新增 Modular Avatar Menu Item、Menu Installer、引用菜单和 Puppet Label 识别。
- 新增 VRCFury Toggle、Puppet、Full Controller、Move/Reorder Menu Item、SPS Options 与旧版 World Constraint 菜单路径识别。
- 同时兼容 VRCFury 新版 `content` 和旧版 `config.features` 序列化结构。
- MA Menu Item 的 `label` 为空时，译文写入 `label`，不再重命名 GameObject。
- 使用 `LGC0001` 稳定编号导出，支持译文乱序回填。
- 增加翻译网页文本清理：兼容全角标点、括号、列表符号、Markdown 代码围栏、HTML 实体、零宽字符、空行丢失等情况。
- 编号全部丢失时，仅在非空行数量完全匹配的情况下按顺序降级解析。
- 增加重复编号、缺失编号、未知编号、空译文和非法路径分隔符检查。
- 增加逐项差异预览、搜索、只显示变化、全选和取消选择。
- 增加 Unity Undo、Prefab 实例覆盖记录、场景脏标记和扫描后内容变化检查。
- 默认阻止直接修改 `Packages/` 内的菜单资源，可由用户明确启用。
- 工具不再自动保存场景、Prefab 或资源。

### 安装与升级

- 包名保持 `com.lgcchina.t-rename-tool`，可直接覆盖旧版包。
- 要求 Unity `2022.3` 与 VRChat Avatars SDK `3.x`。
- Modular Avatar 和 VRCFury 为可选支持，不作为强制包依赖。
- `2.0.0` 与 `1.0.2` 的操作方式不兼容：旧版提取所有子物体名称，新版只提取菜单显示文字。

### 容易踩的坑

- 不要让翻译网页删除 `LGC0001` 一类编号。
- VRCFury 路径会按层级拆分；单个译文中不能包含 `/` 或 `\`。
- MA 空 `label` 会被写入译文，但 GameObject 名称保持不变，这是预期行为。
- 修改共享的原生菜单资产会影响所有引用该资产的 Avatar。
- 直接修改第三方 Package 资源可能在包更新时丢失，默认已禁止。
- 应用后需要用户自行保存场景或资源；工具只负责修改与 Undo 记录。
